# Beadline Hand

Push-pull bead-and-cord tendon hand simulation. Open index.html in a browser.

## Use
Open `index.html` in a browser. Tabs: Simulator, Envelope, Field map, Test plan, Build kit, Sources.

## Build kit
Enter your middle-finger length, then download the kit (.zip): parametric OpenSCAD parts, `make_stl.sh`, a parts list and a report. Run `sh make_stl.sh` with OpenSCAD 2019.05 or newer to get STL files. Downloads work from the saved file or a hosted page, not from embedded previews.

## Status
The simulation is a first-pass estimate. The OpenSCAD parts have not been rendered or test-printed, and the parts list is a suggestion, not a verified supplier list.
